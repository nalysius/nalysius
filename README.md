## Why OpenBSD?

I use OpenBSD in production for 3+ years. Simplicity, security by default,
excellent documentation. I love its coherent configuration syntax and
built-in tools (pf, httpd, relayd, vmm).

Fun fact: OpenSSH is developed by the OpenBSD team, it's installed on
most Linux distributions you know.
